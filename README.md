📚 Bookly – Book Management Web App

Bookly is a simple Book List Web Application built using HTML, CSS, and JavaScript.
It allows users to add books, view them in a card format, and delete books easily using a popup form.

🚀 Features
✅ Displays book details (Title, Author, Description)
✅ Popup form to add a new book
✅ Delete book option
✅ Simple and clean UI
✅ Responsive layout (basic)
🛠️ Technologies Used
HTML5
CSS3
JavaScript
